# Tools

## Measure (interactive)

Pick two points (geometry vertices, mesh nodes, or snapped hits): distance. Consecutive segments sharing a vertex: angle. Cancel in-progress segment by clicking the start point again. Drawn as viewport overlays, not as geometry.

## Dimension / query

On selection, report:

- Distance (two points or parallel entities)
- Length (edge)
- Angle (two edges)
- Radius (circular edge/face)
- Area, volume
- Bounding box
- Centroid

Output in the properties panel and console, in display units.
